# Security Policy

## Reporting a vulnerability

Please do not publish exploit details, credentials, personal data, or proof-of-concept attacks in a public issue.

Use GitHub's **Report a vulnerability** option in the repository's Security tab to submit a private report. Include the affected version or commit, impact, reproduction steps, and any suggested mitigation.

## Supported versions

Only the latest maintained version on the default branch is considered supported unless a release explicitly states otherwise.

## Response

Reports will be reviewed as soon as reasonably possible. Do not assume a report is fixed until a patched commit or release is published.
